## Scaffold

```bash
pnpm create devstack-app my-app
cd my-app
pnpm install
```

The scaffold gives you:

- `devstack.config.ts` — the single source of truth for your stack.
- `move/` — an empty Move package (`./move/hello`) you can ignore or
  expand.
- `src/main.tsx` — a React app that reads `./generated/manifest.json`
  via `fromManifest()`.
- `playwright.config.ts` and an example `e2e/smoke.spec.ts`.
- `vitest.config.ts` and a sample `tests/balance.test.ts`.

## Boot the stack

```bash
pnpm dev
```

The TUI shows each Ref's lifecycle (`pending` → `acquiring` →
`ready`). Localnet runs as a docker container labelled
`devstack.app=my-app`; quit with `q` and devstack tears it down. Force
a full restart with `r`; one Ref failing leaves siblings running so
you can fix it and retry.

## Anatomy of `devstack.config.ts`

The generated file looks like:

```ts
import { devstack, Sui, Account, Package, Bindings, Dev } from '@mysten-incubation/devstack';

const alice = Account('alice', { funding: { SUI: 1_000_000_000n } });
const hello = Package('hello', './move/hello', { signer: alice });

export default devstack(
	Sui(),
	alice,
	hello,
	Bindings({ packages: [hello], output: './src/generated' }),
	Dev({ command: 'vite', args: ['--port', '5173'] }),
);
```

Every line returns a **Ref** — a typed handle that's simultaneously
an Effect Layer, a yieldable tag (`yield* hello` resolves to the
published package's `{packageId, captured, …}`), and a value you can
pass into other factories (`signer: alice`). The supervisor composes
them into one layered graph, orders acquisition by dependency, and
holds them open until you quit. [Refs and tags](./concepts/refs-and-tags)
covers the model.

## Read the manifest

Once the stack is up, every consumer reads from one place:

```ts
import { fromManifest } from '@mysten-incubation/devstack';
import manifestJson from './generated/manifest.json' with { type: 'json' };

const manifest = fromManifest(manifestJson);
const rpcUrl = manifest.services.sui?.rpc.url;          // 'http://sui.my-app.localhost:9000'
const packageId = manifest.packages.hello.id;           // '0x...' (new on every chain wipe)
const aliceAddress = manifest.accounts.alice.address;   // '0x...' (stable per stack)
```

The manifest is regenerated whenever the supervisor's state changes —
package republished, account refunded, walrus deployed — so apps that
read it always see the live values without coordinating their own
cache invalidation.

## Test against a real stack

`pnpm test` runs vitest against a per-test stack named `test`. The
fixture boots and tears down the same Refs your dev session uses, so
unit tests never lie about what the production path does:

```ts
// tests/balance.test.ts
import { devstackTest } from '@mysten-incubation/devstack/vitest';
import config from '../devstack.config.js';

const test = devstackTest(config);

test('alice receives funding at boot', async ({ stack }) => {
	const alice = await stack.account('alice');
	const balance = await stack.client().getBalance({ owner: alice.address });
	expect(BigInt(balance.totalBalance)).toBeGreaterThan(0n);
});
```

`pnpm test:e2e` does the same for Playwright. The `webServer` config
just spreads `playwrightWebServer({ endpoint: 'dev-server' })` — the
URL is sourced from the manifest, so Playwright never races the
supervisor for port allocation.

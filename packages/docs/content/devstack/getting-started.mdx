## Prerequisites

- **Node.js 24+** and **pnpm 10+**. Node 24 strips TypeScript annotations natively, so
  `devstack.config.ts` loads via plain `import()` — no tsx, ts-node, or pre-build step.
- **Docker Desktop** (or Colima) running. devstack ships sui-localnet, walrus, and seal as
  containers.
- **Apple Silicon or Linux x86_64.** Native execution only — no Rosetta or qemu.
- **Sui CLI** (>= 1.51.1) on PATH. Required for codegen and live-network publishes; localnet
  publishes use the in-container CLI.

## Install

```sh
pnpm add -D @mysten-incubation/devstack
```

## Configure

Create a `devstack.config.ts` in your app root:

```ts
import { codegen, defineDevstackConfig, sui, vite } from '@mysten-incubation/devstack';

export default defineDevstackConfig({
	app: 'my-app',
	accounts: {
		publisher: {},
		alice: {},
		bob: {},
	},
	plugins: [sui(), codegen(), vite({ port: 5173 })],
});
```

Account names declared at the top level are funded on localnet via the faucet. Empty objects (`{}`)
get a per-stack generated keypair on disk; live-network deployments override per network — see the
[accounts page](/docs/authoring/accounts).

The [`vite()` plugin](/docs/plugins/vite) brings the dev server up alongside the rest of the stack
so a single `pnpm dev` script handles localnet + publishes + codegen + the UI dev server in one
combined process.

## Bring it up

Wire your `package.json` scripts to the `devstack` binary:

```jsonc
{
	"scripts": {
		"dev": "devstack watch",
		"localnet:up": "devstack up --once",
		"apply": "devstack apply",
		"codegen": "devstack codegen",
		"deploy": "devstack deploy",
		"stack": "devstack stack",
	},
}
```

Then:

```sh
pnpm dev                        # one combined process: stack + dev server
```

The supervisor brings up sui-localnet, fund accounts, publish Move packages, regenerate codegen
bindings, and start the Vite dev server — all in one log stream. Re-run is fast (~1–3 s) because
each action's `getStatus` skip predicate short-circuits work that hasn't drifted.

For a single bring-up + exit (CI / e2e setup):

```sh
pnpm exec devstack up --once    # ~17 s cold, ~1.2 s warm
```

For a single cycle without the supervisor (CI-friendly, also works against testnet/mainnet):

```sh
pnpm exec devstack apply
```

## What happened

1. The `sui` plugin built `dev-examples/sui-localnet:<version>`, started a container, and
   provisioned the keypairs you declared in `accounts:`.
2. Each `definePublishAction` (or `publish()`) action ran `sui move build` + a publish tx and
   recorded the package id in the manifest.
3. `codegen` regenerated typed bindings under `src/generated/sui/<package>/`.
4. The manifest was written to `<appDir>/.devstack/stacks/main/manifest.json`. Your Vite-built
   frontend reads it via the `virtual:devstack-manifest` module.

---
title: Networks and accounts
---

Devstack's interface tags (`Sui`, the account tags, `WalrusNetwork`, `SealKeyServer`,
`DeepbookCore`) let one program target localnet, testnet, mainnet, or a custom node by swapping
one line in the stack. This guide covers the swap mechanics and the four account sources.

## The two axes

Consumer code yields interface tags, not factory shapes:

```ts
const sui = yield* Sui;           // not yield* suiLocalnet()
const alice = yield* a.alice;     // not yield* (specific signer impl)
```

So the same `Effect.gen` body runs against any `Sui` factory and any account source. The
config picks both:

| Axis                  | Factory varies by                                       |
| --------------------- | ------------------------------------------------------- |
| **Sui chain**         | `suiLocalnet()` / `suiTestnet()` / `suiMainnet()` / `suiCustom()` |
| **Account source**    | `accounts({ from: 'ephemeral-funded' \| 'env' \| 'keystore' \| 'inline' })` |

Pick each independently. A common production pattern uses `suiTestnet()` with `from: 'env'`.

## Switching networks

```ts
// Same `defineDevstack` shape, different chain.
const sui =
	process.env.NODE_ENV === 'production' ? suiTestnet() : suiLocalnet();

export default defineDevstack([
	sui,
	a.alice,
	helloPublish,
	manifest(),
]);
```

| Factory                     | Provides                                      | Notes                                                            |
| --------------------------- | --------------------------------------------- | ---------------------------------------------------------------- |
| `suiLocalnet({ version? })` | RPC + faucet + GraphQL + indexer (containerized) | Cold boot ~30s. Default; matches the template.                |
| `suiTestnet()`              | RPC + faucet (remote URLs)                    | No container. Faucet rate-limited.                               |
| `suiMainnet()`              | RPC only (remote URL)                         | No faucet. Read-mostly workloads.                                |
| `suiCustom({ rpcUrl, faucetUrl?, chainId })` | Whatever you pass | Corporate fullnodes, pinned forks, air-gapped mirrors.   |

Primitives that **only make sense on localnet** (the local `walrusLocalCluster`, the local
`sealLocalKeygen`, the local `deepbookLocalDeploy`) refuse to acquire on a non-localnet chain.
The `*Known*` variants are the live-net counterparts.

## Account sources

```ts
const a = accounts({
	alice: { from: 'ephemeral-funded' },                     // default; same as {}
	bob: { from: 'keystore', alias: 'bob' },
	deployer: { from: 'env', key: 'DEPLOYER_PRIVATE_KEY' },
	fixture: { from: 'inline', key: 'suiprivkey1...' },
});
```

| `from`               | Where the key comes from                                           | Funded?              | Persists?                                  |
| -------------------- | ------------------------------------------------------------------ | -------------------- | ------------------------------------------ |
| `'ephemeral-funded'` | Fresh Ed25519 keypair, generated on first acquire                  | Yes (faucet)         | Yes — `.devstack/stacks/<stack>/.keys/`    |
| `'env'`              | `process.env[key]` — must be a `suiprivkey1…` string                | No                   | No                                         |
| `'keystore'`         | `~/.sui/sui_config/sui.keystore`, looked up by alias or address     | No                   | No (read each acquire)                     |
| `'inline'`           | Literal `key: 'suiprivkey1…'`                                       | No                   | No                                         |

The bare `{}` form is shorthand for `{ from: 'ephemeral-funded' }`.

### When to use which

- **`ephemeral-funded`** — local development. Faucet funds it, keys persist across restarts so
  on-chain state references stay valid.
- **`env`** — CI and production. Secrets come from your secrets manager via env vars; no
  disk persistence; faucet not assumed.
- **`keystore`** — local development against testnet where you already have a funded address.
  Lets you publish from the same address as `sui client publish`.
- **`inline`** — test fixtures only. Embeds a key in source; don't ship it.

## The same program in dev and prod

```ts
import { Effect } from 'effect';
import { runMain } from '@effect/platform-node/NodeRuntime';
import {
	accounts,
	provideDevstack,
	Sui,
	suiLocalnet,
	suiTestnet,
} from '@mysten-incubation/devstack';

const a =
	process.env.NODE_ENV === 'production'
		? accounts({ alice: { from: 'env', key: 'ALICE_PRIVATE_KEY' } })
		: accounts({ alice: { from: 'ephemeral-funded' } });

const program = Effect.gen(function* () {
	const sui = yield* Sui;
	const alice = yield* a.alice;
	yield* Effect.log(`sui ${sui.network} @ ${sui.rpc.host}`);
	yield* Effect.log(`alice ${alice.address}`);
	// ...
});

const layer =
	process.env.NODE_ENV === 'production'
		? provideDevstack([suiTestnet(), a.alice])
		: provideDevstack([suiLocalnet(), a.alice]);

runMain(program.pipe(Effect.provide(layer)));
```

`program` is identical in dev and prod. The layer picks the chain and the key source; nothing
else changes. See [Effect programs](/devstack/guides/effect-programs) for the full pattern.

## Faucet on suiCustom

`suiCustom` accepts a `faucetUrl` so the `ephemeral-funded` source still works on bespoke
chains:

```ts
suiCustom({
	rpcUrl: 'https://my-fullnode.internal',
	faucetUrl: 'https://my-faucet.internal',
	chainId: 'abcdef01',
});
```

Without a faucet, `accounts({ from: 'ephemeral-funded' })` fails at acquire time. Use a
non-funded source (`env`, `keystore`, `inline`) when the chain has no faucet.

## Common pitfalls

- **`ephemeral-funded` on mainnet** — refuses at acquire time. Mainnet has no faucet; the
  primitive fails fast rather than silently producing an unfunded account.
- **`from: 'env'` with missing env var** — the supervisor reports `ALICE_PRIVATE_KEY not set`
  at acquire time. Source your env file before `pnpm dev`.
- **Keystore alias collisions** — if the alias resolution falls back to address matching and
  multiple entries match, the primitive fails. Use the alias field on the sibling `sui.aliases`
  file for an unambiguous lookup.

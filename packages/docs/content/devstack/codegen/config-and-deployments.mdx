Devstack resolves a typed config object from a per-network **deployment**. A `NetworkDeployment`
carries everything an app needs to talk to one network (rpc, chainId, faucet, graphql, accounts,
package ids, mvrOverrides, values); a `DevstackDeployment` envelope holds one per network. The config
is read once, with a single loud failure if it is missing.

---
title: Refs and Tags
description: The current stack-member substrate model.
---

Every root factory returns a stack member. A member has:

- `provides`: the tag for the resolved value it publishes.
- `consumes`: tags that must resolve before it can acquire.
- `kind`: lifecycle classification for the supervisor.
- `acquire`: the effect that produces the resolved value.
- `capabilities`: optional declarations for routing, snapshots, strategies, generated files, and
  composites.

The public helpers are available from the root export and from the `substrate` subpath when you want
smaller imports:

```ts
import {
	defineNodePlugin,
	defineTag,
	capabilities,
	consumeMember,
} from '@mysten-incubation/devstack';
```

Direct member references are the public cross-plugin pattern:

```ts
const publisher = account('publisher');
const hello = localPackage('hello', {
	sourcePath: './move/hello',
	publisher,
});
```

The package factory projects `publisher.provides` into its `consumes` tuple. The supervisor then
orders the publisher before the publish step, and TypeScript can report a missing provider at the
`defineDevstack(...)` call site.

Subpaths:

- `@mysten-incubation/devstack/substrate` exports brands, tags, lifecycle types, manifest types, and
  stack-member shapes.
- `@mysten-incubation/devstack/contracts` exports capability declaration types.

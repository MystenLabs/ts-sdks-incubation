---
title: Going to production
description: Take a devstack app to production — declare the network set, hand-write typed deployments, switch networks in dapp-kit, and ship a build with no local artifacts.
---

Going to production is a first-class devstack path, not an appendix. The same multi-network config
that runs your local stack also drives a production build: you declare the live network set, author
typed `deployments/<network>.ts` files for each, wire dapp-kit to switch between them, and ship a
build where local-mode networks (and the dev wallet) are dropped.

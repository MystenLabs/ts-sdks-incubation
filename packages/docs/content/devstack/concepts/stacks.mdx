---
title: Stacks
description:
  Named per-app environments — switch between main and scratch without trashing your working chain.
---

A **stack** is a per-app named environment. Each stack maps to an isolated set of docker
containers + a docker network + a host-side state dir at `<appDir>/.devstack/stacks/<stack>/`
(holding manifest, keys, ports.json, setup markers). Container names embed the stack
(`<app>-<stack>-sui`), so multiple stacks for the same app can coexist on one host. The per-stack
port allocator persists assignments to `<stackDir>/ports.json` and reads sibling stacks'
allocations so collisions never happen across stacks of the same app.

State lives in either the container's writable layer (chain ledger, walrus blob store —
preserved across `docker stop`/`docker start`, captured for snapshots via `docker commit`) or the
host stack dir. No named docker volumes.

The active stack is whatever `<appDir>/.devstack/active` says, falling back to `'main'`. Override
with `DEVSTACK_STACK=other` env var, or pin via `--target <stack>` / `--target localnet:<stack>` on
most CLI verbs.

## Common workflows

```sh
pnpm exec devstack stack list                # See every stack, marked active
pnpm exec devstack stack new scratch         # Create empty
pnpm exec devstack stack use scratch         # Switch (stops the previous stack's containers)
pnpm exec devstack up                        # Bring scratch up
pnpm exec devstack stack use main            # Switch back
pnpm exec devstack stack drop scratch --yes  # Delete scratch entirely
```

`drop` refuses to drop `main` and the active stack unless `--force` is passed. The `devstack reset`
shortcut auto-passes `--force` against the active stack — wipe-and-restart in one command.

## Live networks ignore stacks

`devstack apply --target testnet` and `devstack deploy --network testnet` operate on a network-keyed
manifest at `<appDir>/.devstack/manifests/testnet.json`. The `--stack` flag and active-stack pointer
are ignored on live nets — there's only one `testnet` per app, so a stack dimension would be
confusing.

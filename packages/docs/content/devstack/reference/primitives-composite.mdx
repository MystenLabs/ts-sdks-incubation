Reference for the bigger primitives — Walrus storage, Seal threshold encryption, DeepBook order
book. For task-oriented walkthroughs see the [Walrus](/devstack/guides/walrus),
[Seal](/devstack/guides/seal), and [DeepBook](/devstack/guides/deepbook) guides.

## Walrus

Two factories, four interface tags.

### `walrusLocalCluster`

```ts
import { walrusLocalCluster } from '@mysten-incubation/devstack';

walrusLocalCluster({
	name?: string,                                      // Default 'walrus'.
	nodeCount?: number,                                 // Default 4.
	shards?: number,                                    // Default 100; must be >= nodeCount.
	seedAccounts?: ReadonlyArray<PluginTag<…, Account, …>>,
	seedPaymentMist?: bigint,                           // Default 500_000_000n (0.5 SUI).
	version?: string,                                   // Default 'walrus-v1.39.0'.
	suiVersion?: string,                                // Default 'devnet-v1.71.0'.
	containerApiPort?: number,                          // Default 9185.
	epochDuration?: string,                             // Default '24h'.
	readyTimeoutMs?: number,                            // Default 60_000.
	movePackagePath?: string,                           // Override the Move source fetch.
});
```

Provides all four interface tags: `WalrusNetwork`, `WalrusNodes`, `WalrusProxy`, `WalrusAdmin`.
The local-cluster body acquires nodes, proxy, and seed-WAL in order; consumers see one TUI row.

### `walrusKnownDeployment`

```ts
import { walrusKnownDeployment } from '@mysten-incubation/devstack';

walrusKnownDeployment({
	name?: string,
	network: 'testnet' | 'mainnet',
});
```

Provides only `WalrusNetwork`. Defaults pulled from `knownDeployments.walrus`.

### Interface tags

```ts
interface WalrusNetworkShape {
	readonly proxyUrl: string;
	readonly systemObjectId: string;
	readonly stakingPoolId: string;
	readonly suiPackageId: string;
}

interface WalrusNodesShape {
	readonly nodes: ReadonlyArray<{
		readonly id: string;
		readonly apiUrl: string;
		readonly publicKey: string;
	}>;
}

interface WalrusProxyShape {
	readonly url: string;
}

interface WalrusAdminShape {
	readonly adminAccount: Account;
	readonly signAdminTx: (...) => Effect.Effect<TxResult, ...>;
}
```

## Seal

### `sealLocalKeygen`

```ts
import { sealLocalKeygen } from '@mysten-incubation/devstack';

sealLocalKeygen({
	name?: string,                              // Default 'seal'.
	signer: PluginTag<…, Account, …>,
	version?: string,
	suiVersion?: string,
	keyServerPort?: number,                     // Default 2024 (allocator-rebased).
	readyTimeoutMs?: number,                    // Default 60_000.
	movePackagePath?: string,
});
```

Provides both `SealKeyServer` (read surface) and `SealKeyManager` (local admin surface). The
master keypair persists under `.devstack/stacks/<stack>/.seal/` across `devstack wipe` —
delete manually for a fresh server identity.

### `sealKnownKeyServer`

```ts
import { sealKnownKeyServer } from '@mysten-incubation/devstack';

sealKnownKeyServer({
	name?: string,
	network: 'testnet' | 'mainnet',
});
```

Provides only `SealKeyServer`. Defaults pulled from `knownDeployments.seal`.

### Interface tags

```ts
interface SealKeyServerShape {
	readonly objectId: string;
	readonly keyServerUrl: string;
	readonly publicKey: Uint8Array;
}

interface SealKeyManagerShape {
	readonly envFilePath: string;
	readonly rotate: Effect.Effect<void, SealError, never>;
}
```

## DeepBook

Three factories. `local-deploy` owns the admin cap and can mint a BalanceManager (so it
provides all three interface tags); `known-package` provides only `DeepbookCore`;
`market-maker` provides `DeepbookMarketMaker` on top of an existing deployment.

### `deepbookLocalDeploy`

```ts
import { deepbookLocalDeploy } from '@mysten-incubation/devstack';

deepbookLocalDeploy({
	name: string,
	signer: PluginTag<…, Account, …>,
	movePackagePath?: string,                   // Override the Move source.
	pools: ReadonlyArray<DeepbookPoolSpec>,
});
```

```ts
interface DeepbookPoolSpec {
	readonly name: string;
	readonly base: string | PublishedCoin;
	readonly quote: string | PublishedCoin;
	readonly tickSize: bigint;
	readonly lotSize: bigint;
	readonly minSize: bigint;
}
```

`base` / `quote` accept either a static type string (`'0x2::sui::SUI'`) or a `PublishedCoin`
from `publishMove({ coins: {...} })`. Pool ids are cached per
`(chainId, packageId, pool-spec hash)` so warm restarts skip `create_pool_admin` (which would
abort on duplicate registrations).

### `deepbookKnownPackage`

```ts
import { deepbookKnownPackage } from '@mysten-incubation/devstack';

deepbookKnownPackage({
	name?: string,
	network: 'testnet' | 'mainnet',
});
```

Provides only `DeepbookCore`. Defaults from `knownDeployments.deepbook`.

### `deepbookMarketMaker`

```ts
import { deepbookMarketMaker } from '@mysten-incubation/devstack';

deepbookMarketMaker({
	name: string,
	signer: PluginTag<…, Account, …>,
	pools: ReadonlyArray<{
		name: string;
		base: string | PublishedCoin;
		quote: string | PublishedCoin;
		tickSize: bigint;
		midPrice: bigint;
		sizePerLevel: bigint;
	}>,
	dependsOn?: ReadonlyArray<PluginTag<…>>,
});
```

Provides `DeepbookMarketMaker`. Posts a multi-level ladder around `midPrice` on each pool and
keeps it refreshed. `signer` must have base + quote inventory before the maker's first tick
(use `dependsOn:` on whatever primitive seeds it).

### Interface tags

```ts
interface DeepbookCoreShape {
	readonly packageId: string;
	readonly registryId: string;
	readonly pools: Record<string, DeepbookPool>;
	readonly findPool: (name: string) => DeepbookPool | undefined;
}

interface DeepbookAdminShape {
	readonly adminCapId: string;
	readonly signAdminTx: (...) => Effect.Effect<...>;
}

interface DeepbookMarketMakerShape {
	readonly balanceManagerId: string;
}
```

## Known deployments registry

`knownDeployments` carries the static URL / object-id sets for `*Known*` factories:

```ts
import { knownDeployments, type KnownNetwork } from '@mysten-incubation/devstack';

knownDeployments.walrus.testnet;
knownDeployments.seal.testnet;
knownDeployments.deepbook.mainnet;
```

The factories read from this map by default; you can override on a per-factory basis by
passing the relevant URL/id options.

The package bin is `devstack`.

Global flags include `--json`, `--app <name>`, `--stack <name>`, `--state-dir <path>`,
`--config <path>`, `--network <name>`, `--renderer tui|plain|silent`, `--dry-run`, `--yes`,
`--no-input`, `--verbose`, `--schema`, `--version`, and `--help`.

## Core commands

```bash
devstack up
devstack down
devstack apply
devstack status
devstack logs <plugin>
devstack exec -- <command> [args...]
devstack doctor
devstack config
devstack codegen
```

`up` stays attached to the supervisor. `apply` boots, reconciles, emits generated files, and exits.
Peer commands such as `down`, `logs`, and `snapshot` communicate with the running supervisor through
the stack command/event files.

## Stack commands

```bash
devstack stack list
devstack stack new <name>
devstack stack use <name>
devstack stack drop <name>
devstack stack drop-fork <name>
```

## Snapshot commands

```bash
devstack snapshot save [--label <label>]
devstack snapshot restore <id-or-label>
devstack snapshot list
devstack snapshot delete <id-or-label>
```

Snapshot support is stack-scoped and identity-guarded. See
[state and snapshots](../features/state-and-snapshots).

## Fork commands

```bash
devstack fork status
devstack fork advance --ms <milliseconds>
devstack fork seed
devstack fork replay
devstack fork cache
```

Use `--schema --json` to print the command tree consumed by automation.

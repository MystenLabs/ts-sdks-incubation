Import these from `@mysten-incubation/devstack`.

## `defineDevstack({ members, ...options })`

Object-form stack composer. `members` are entrypoints; plugin-valued dependencies are included
recursively. Options include `stackName`, `network`, `watchPaths`, `stateDir`, `renderer`,
`hotRestart`, `extras`, and `codegen`.

## `sui(opts?)`

Starts or references the active Sui network. Modes include local, live, fork, and external. Include
one `sui(...)` member in any stack whose members depend on Sui. The `sui()` factory returns a plugin
resource ref, so custom plugins can depend on a specific Sui member directly:

```ts
import { Effect } from 'effect';
import { defineDevstack, definePlugin, sui } from '@mysten-incubation/devstack';

const localnet = sui({ mode: 'external', rpcUrl: 'http://127.0.0.1:9000' });
const app = definePlugin({
	id: 'app',
	dependsOn: { sui: localnet },
	kind: 'leaf-long-running',
	start: (_ctx, { sui }) => Effect.succeed({ rpc: sui.rpcUrl }),
});

export default defineDevstack({ members: [localnet, app] });
```

## `account(name, opts?)`

Creates a named identity. Variants: `ephemeral`, `keystore`, `env`, `inline`, `signer`, and
`impersonate`. Cross-coin funding is `funding: [{ coin, amount }]`.

## `localPackage(name, opts)`

Builds and publishes a local Move source tree.

```ts
const publisher = account('publisher');
const hello = localPackage('hello', {
	sourcePath: './move/hello',
	publisher,
	capture: { objectId: '::hello::Hello' },
});
```

Options include `sourcePath`, `publisher`, `resolveSourcePath`, `mvrPlaceholder`,
`excludeFromCodegen`, and `capture`.

## `knownPackage(name, opts)`

Verifies a fixed on-chain module by id. Options include `packageId`, `upgradeCapId`, and
`mvrPlaceholder`.

## `coin`

Namespace forms: `coin.builtin('sui')`, `coin.fromPackage(member, witness)`, `coin.local(symbol)`,
and `coin.known(fullCoinType)`.

## `wallet(opts?)`

Starts the dev wallet HTTP server and emits generated dapp-kit config. Use `wallet()`,
`wallet({ accounts: 'all' })`, or `wallet({ accounts: [alice, bob] })`.

## `faucet(opts?)`

Creates a faucet dispatcher and registers caller-supplied strategies. Most local SUI funding is
handled by the Sui strategy registered for the active chain. `faucet()` is a dependency-free plugin
resource ref.

## `postgres(opts?)`

Starts a local Postgres container and emits generated connection bindings. `postgres()` is a
dependency-free plugin resource ref; set `route: true` only when you need the TCP router entrypoint.

## `action(name, opts)`

Runs a one-shot on-chain effect after its consumed members are ready.

```ts
const open = action('open-lobby', {
	dependsOn: { signer: publisher, pkg: hello },
	body: (ctx, { signer, pkg }) =>
		ctx.signAndExecute(signer, (tx) => {
			tx.moveCall({ target: `${pkg.packageId}::hello::open` });
		}),
});
```

## `walrus`, `seal`, `deepbook`

Composite service factories. See [services](../features/services) for current mode caveats.

## `runStack(stack, opts?)`

Programmatic runtime embedding. Returns `{ start, stop, awaitShutdown, events, state }`.

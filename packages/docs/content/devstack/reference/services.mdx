Every factory below returns a [Ref](../internals/refs-and-tags). Pass
them into `devstack(...)` to compose the stack.

For task-shaped guidance ("how do I run a dev server?", "how do I
fund an account?"), start with a feature page like
[local-dev](../features/local-dev) or
[accounts-and-wallet](../features/accounts-and-wallet). This page is
the API surface — every option, every shape, every default.

## `Sui(opts?)`

The canonical sui factory. Defaults to localnet (vendored image with
embedded faucet + indexer postgres + GraphQL).

```ts
Sui();                                      // localnet (default)
Sui({ network: 'testnet' });                // public testnet RPC
Sui({ network: 'mainnet' });                // public mainnet RPC
Sui({ network: { rpc: 'https://example.com', faucet: 'https://example.com/faucet' } });
Sui({ localnet: { rpcUrl: 'http://localhost:9000' } });  // wrap your own
```

Yields `Sui`: `{ network, rpc, faucet?, graphql?, client, chainId,
waitForTransactionsReady }`.

## `Account(name, opts?)`

A single named account.

```ts
Account('alice');                                                   // ephemeral-funded
Account('alice', { funding: { SUI: 1_000_000_000n, WAL: 50n } });   // multi-coin funding
Account('ci', { from: 'env', key: 'ALICE_PRIVATE_KEY' });
Account('mike', { from: 'keystore', alias: 'mike' });
Account('test', { from: 'inline', privateKey: 'suiprivkey1...' });
Account('hsm', { from: 'signer', signer: myHardwareSigner });
```

Source discriminators:

- `'ephemeral-funded'` (default) — generate a fresh ed25519 keypair,
  persist it under `.devstack/stacks/<stack>/.keys/<name>.key`, and
  request faucet funding.
- `'keystore'` — read from `~/.sui/sui_config/sui.keystore`.
- `'env'` — read a `suiprivkey1...` from `process.env[key]`.
- `'inline'` — accept a literal `suiprivkey1...` string (tests/demos
  only).
- `'signer'` — accept any `@mysten/sui/cryptography` `Signer`
  instance. HSMs, remote signers, browser-connected wallets — devstack
  never asks for `getSecretKey()` on this branch.

The optional `funding` field works on **any** source. CoinTag keys are
short names for built-ins (`'SUI'`, `'WAL'`) or fully-qualified Move
types for user coins. See [Faucet reference](./faucet) for the
strategy registry that backs it.

## `Package(name, source, opts)`

Publish a Move package from a local source tree.

```ts
const hello = Package('hello', './move/hello', {
	signer: alice,
	mvr: '@local/hello',                  // optional; defaults to `@local/<slug>`
	capture: {                             // optional declarative form
		adminCap: 'hello::admin::AdminCap',
		registry: 'hello::store::Registry',
	},
	coins: [{ name: 'gold', module: 'gold', type: 'GOLD', decimals: 9 }],
	codegen: true,                         // default; `false` excludes from Codegen
});
```

Yields `LocalPackage`: `{ name, packageId, upgradeCapId,
sourcePath, mvrPlaceholder, captured }`.

`captured` is whatever the `capture` callback returned (declarative
form: `Record<key, objectId>`; callback form: whatever you return).

## `KnownPackage(name, opts)`

A `Package`-shaped Ref backed by a fixed on-chain id — for
referencing testnet/mainnet packages without publishing.

```ts
const deepbookV3 = KnownPackage('deepbook', {
	packageId: '0xdee...',
	mvrPlaceholder: '@mvr/deepbook',
});
```

Yields `Package` (no `sourcePath`/`captured`). `Codegen` /
`Codegen`'s bindings emitter skips entries without source; emitters that just need
the id (DappKit, custom emitters) consume it.

## `Action(name, opts)`

A one-shot transaction the supervisor runs once per chain.

```ts
const seedAlice = Action('seed-alice', {
	signer: alice,
	needs: [hello],
	cacheKey: Effect.gen(function* () {
		const pkg = yield* hello;
		return `seed/${pkg.packageId}`;
	}),
	build: (t) => Effect.gen(function* () {
		const pkg = yield* hello;
		t.moveCall({
			target: `${pkg.packageId}::store::seed`,
			arguments: [t.pure.u64(100n)],
		});
	}),
});
```

`cacheKey` folds in `sui.chainId + signer.address` automatically, so a
fresh genesis naturally misses the cache. Omit `cacheKey` to fire on
every cycle (rare — usually a bug).

## `Walrus(opts?)`, `Seal(opts?)`, `Deepbook(opts?)`

Composite Refs that surface four narrow interfaces apiece. Each
factory inspects `DEVSTACK_NETWORK` (set by the CLI `--network` flag,
the `devstack({ network })` config option, or the env var directly)
and branches: on localnet it boots a full local cluster; on
testnet/mainnet it wires to Mysten's canonical remote deployment.

```ts
Walrus();                                   // local cluster on localnet, canonical remote otherwise
Walrus({ local: { nodeCount: 4 } });        // tune the local cluster (ignored on live nets)
Walrus({ override: { packageId, ... } });   // pin a non-canonical deployment on live nets

Seal({ signer: alice });                    // signer used only on localnet
Deepbook({ local: { signer, ... } });       // local-deploy fields used only on localnet
DeepbookMarketMaker({ pools: [...] });      // continuous liquidity (any network)
```

Yield the narrow inner tags directly when you only need a slice —
`yield* WalrusNodesTag`, `yield* SealKeyServerTag`, `yield* DeepbookCoreTag`.
The admin-side tags (`WalrusAdminTag`, `SealKeyManagerTag`,
`DeepbookAdminTag`) only exist on localnet — yielding them from code
that may run against testnet/mainnet will fail at acquire time.

## `Dev(opts)`

Run a long-running host process — usually a Vite dev server.

```ts
Dev({
	command: 'vite',
	args: ['--port', '5173'],
	port: 5173,                              // preferred host port
	ready: { kind: 'http', path: '/', expectedStatus: 200 },
	needs: [hello, bindings],                // hold start until ready
});
```

Surfaces a routed `http://dev.<app>.localhost` URL alongside the host
port. The manifest's `app.dev.url` carries it; Playwright's
`webServer` config reads from there.

## `Wallet(opts)`

The dev-only signing-server UI. Opt-in; `devstack(...)` does not
auto-mount it.

```ts
Wallet({ accounts: [alice, bob] });
```

Exposes a localhost HTTP API that signs transactions with the
resolved accounts' keypairs. Allowed origins, port, and bind address
are configurable.

## `Codegen(opts)`

The code-emit Ref. With no `emitters` field, defaults to
`[BindingsEmitter()]` (Move → TS bindings via `@mysten/codegen`).
Override `emitters` to combine multiple emitters or swap in user
emitters.

```ts
// Default: bindings only.
Codegen({ packages: [hello, world], output: './src/generated' });

// Explicit: bindings + dapp-kit emitter. Both live under /advanced.
import { BindingsEmitter, DappKitEmitter } from '@mysten-incubation/devstack/advanced';

Codegen({
	output: './src/generated',
	packages: [hello, deepbookV3],
	emitters: [BindingsEmitter(), DappKitEmitter({ flavor: 'react' })],
});
```

See [Codegen reference](./codegen) for the emitter plug-in interface.

## `DappKit(opts)`

Convenience facade over `Codegen({ emitters: [DappKitEmitter()] })`.

```ts
DappKit({
	packages: [hello],
	output: './src/generated',
	flavor: 'react',                         // default
});
```

The emitted file lives at `<output>/dapp-kit/index.ts` and is what
your `main.tsx` imports. See [Codegen reference](./codegen) for the
flavor options.

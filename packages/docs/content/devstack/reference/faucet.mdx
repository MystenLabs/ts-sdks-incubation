---
title: Faucet Reference
description: Current faucet dispatcher and strategy helpers.
---

The root exports include:

- `faucet`
- `defineFaucetStrategy`
- `faucetCapabilityKey`
- `suiLocalStrategy`
- `suiLiveStrategy`
- `requestFundsOnce`
- `requestFundsWithRetry`

Use `faucet()` when you need a dispatcher member or custom chain strategies.

```ts
import { defineDevstack, faucet, suiLiveStrategy } from '@mysten-incubation/devstack';

const customFaucet = faucet({
	strategies: [
		{
			chainId: 'sui:testnet',
			strategy: suiLiveStrategy({ network: 'testnet' }),
		},
	],
});

export default defineDevstack({ members: [customFaucet] });
```

Plugin authors can contribute a strategy through capabilities:

```ts
import { defineFaucetStrategy } from '@mysten-incubation/devstack';

const strategyDecl = defineFaucetStrategy({
	chainId: 'sui:custom',
	strategy: {
		request: ({ address, amount }) => myFundingEffect(address, amount),
	},
});

const caps = [strategyDecl];
```

Accounts use funding entries with direct coin members:

```ts
const alice = account('alice', {
	funding: [{ coin: 'sui', amount: 1_000_000_000n }],
});
```

If no strategy exists for a non-SUI funding entry, that entry is skipped. SUI funding is stricter
and surfaces an acquire error when the active chain has no registered SUI strategy.

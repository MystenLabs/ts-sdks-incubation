---
title: walletServer
description: In-supervisor HTTP server that exposes ctx.accounts to a browser-side signer adapter.
---

`walletServer()` adds an HTTP server to the supervisor that surfaces the resolved `ctx.accounts`
over `/api/v1/devstack/*` so a browser app can sign transactions without ever loading private keys
into the bundle.

It pairs with [`DevstackSignerAdapter`](/dev-wallet/guides/devstack-integration) from
`@mysten-incubation/dev-wallet` — the adapter reads the service URL from
`manifest.registry.services` and signs over HTTP.

## Use

```ts
import {
	codegen,
	defineDevstackConfig,
	frontend,
	sui,
	walletServer,
} from '@mysten-incubation/devstack';

export default defineDevstackConfig({
	app: 'my-app',
	accounts: {
		publisher: {},
		alice: {},
		bob: {},
	},
	plugins: [
		sui({ version: 'devnet-v1.71.0' }),
		// ...app plugins
		codegen(),
		walletServer({ port: 9420 }),
		frontend({ port: 5173 }),
	],
});
```

## Lifecycle

`walletServer()` registers two actions, lifecycle-split so the manifest carries the wallet-server
entry as soon as `apply` mode (Playwright globalSetup, `devstack apply`) completes — even before
the listener is spawned:

| Action                   | Type        | Purpose                                                                                                                                                                          |
| ------------------------ | ----------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `wallet-server.register` | Register    | Allocate the host port via the per-stack port allocator, read or mint the bearer token, populate `manifest.registry.services` with the deterministic `wallet-server` entry.      |
| `wallet-server.serve`    | HostProcess | Spawn a Node `http` server on the allocated port (read from the registry), serving the same token. Close on supervisor stop. Skipped by `applyTestSetupFilter` (test-bring-up).  |

The split avoids a cold-first-run race: a Playwright globalSetup that ran the listener but then
exited used to leave the manifest pointing at a dead server until the dev-server's supervisor took
over. Now `register` populates the manifest unconditionally; `serve` runs only under a long-running
supervisor, where its lifetime matches the listener's.

The server holds an `address → Signer` map populated from `ctx.accounts.names()`. Every named
account in `defineDevstackConfig({ accounts })` becomes signable — `cliSigner`, `envSigner`,
`generatedKeypair`, anything that materializes a `Signer`.

## Endpoints

| Method | Path                                       | Returns                                                                           |
| ------ | ------------------------------------------ | --------------------------------------------------------------------------------- |
| `GET`  | `/health`                                  | `{ ok: true }` — liveness probe, no auth required.                                |
| `GET`  | `/api/v1/devstack/accounts`                | `{ accounts: [{ name, address, scheme, publicKey }] }` — full account snapshot.   |
| `POST` | `/api/v1/devstack/sign-transaction`        | `{ suiSignature, txBytes }` — signs the `txBytes` (base64 BCS `TransactionData`). |
| `POST` | `/api/v1/devstack/sign-personal-message`   | `{ signature, bytes }` — signs an arbitrary message via `signer.signPersonalMessage`. |

All `/api/*` requests require `Authorization: Bearer <token>` or a `?token=<hex>` query parameter.

## Options

```ts
interface WalletServerPluginOptions {
	/** Preferred TCP port. Hint to the per-stack port allocator —
	 * the allocator picks a free port if the preferred one is taken
	 * by a sibling stack. Default 9420. */
	port?: number;
	/** Override the printed origin (e.g. when proxying through a tunnel). */
	publicOrigin?: string;
	/** Names of actions that must run before the server starts. Default
	 * `['sui.accounts']` so funded accounts are available before any sign
	 * request can arrive. */
	needs?: string[];
}
```

## Constraints

- Localnet-only. Calls `requireLocalnetCtx` — `devstack deploy --network testnet` skips this plugin
  entirely.
- The token is persisted to `<stackDir>/wallet-token` and reused across supervisor restarts. The
  manifest is the source of truth for the URL + token — don't persist it client-side.

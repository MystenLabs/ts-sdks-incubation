---
title: frontend
description: Run a Vite (or Next, or any port-flag-aware) dev server alongside the rest of the stack — one process, one log stream.
---

`frontend({ port?, command?, appendPort?, cwd?, needs? })` contributes one `hostProcess` action
that spawns the dev server as a host child process. Output streams through the supervisor's
status renderer (timestamped + prefixed `[vite.dev-server]`), interleaved with the action panel
cleanly. Defaults run `pnpm exec vite --port <port>`; pass `command` to swap in any other tooling
(Next.js, SvelteKit, Astro), and `appendPort: false` if your tool expects a different port flag.

```ts
import { codegen, defineDevstackConfig, frontend, sui } from '@mysten-incubation/devstack';

export default defineDevstackConfig({
	app: 'arena',
	accounts: { publisher: {}, alice: {}, bob: {} },
	plugins: [sui(), arenaPlugin(), codegen(), frontend({ port: 5176 })],
});
```

Each app's `pnpm dev` becomes:

```jsonc
{
	"scripts": {
		"dev": "devstack up",
	},
}
```

`devstack up` runs the long-running supervisor; the frontend plugin's hostProcess action brings up
the dev server alongside sui localnet, walrus, seal, package publishes, codegen — everything in one
process.

| Option       | Default                    | Notes                                                                                                                                                                                                      |
| ------------ | -------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `port`       | `5173`                     | Passed to `vite --port`. Ports 9000/9123 are already taken by sui's RPC + faucet on a default install.                                                                                                     |
| `command`    | `['pnpm', 'exec', 'vite']` | Override the dev-server command. The plugin appends `['--port', String(port)]` unless `appendPort: false`.                                                                                                |
| `appendPort` | `true`                     | When `false`, don't append `--port <port>` to `command`. Useful for tools with a different port flag (e.g. `next dev -p`).                                                                                |
| `cwd`        | `ctx.appDir`               | Override the spawn cwd.                                                                                                                                                                                    |
| `needs`      | `['codegen.generate']`     | Action ordering: vite waits until codegen has emitted bindings + the manifest is written. Pass `[]` to start immediately (the manifest virtual module returns a typed empty fallback before first deploy). |

---
title: arena
description: Shared-object Connect Four.
---

A Connect Four game with on-chain matchmaking. Lobbies are shared objects published once at deploy;
each game is a shared `Game` object. Demonstrates shared-object concurrency, capability patterns,
and devstack's seed action shape.

Source: [`examples/arena/`](https://github.com/mysten-incubation/devstack/tree/main/examples/arena)

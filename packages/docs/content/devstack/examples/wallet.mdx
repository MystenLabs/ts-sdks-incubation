Multi-coin balance UI plus a DeepBook v3 swap interface against locally-published pools with
continuous liquidity from a built-in grid market-maker. Shows how the
[`deepbook()` plugin](/devstack/plugins/deepbook) collapses publish + pool-create + market-maker
into one declarative block, so the frontend trades against a real on-chain book that stays full
between requests.

Stack:

- `sui()` — localnet validator + faucet.
- `deepbook()` — publishes DeepBook v3, creates SUI/mUSDC + SUI/mWETH whitelisted pools, runs
  alice's grid maker that quotes 3 levels per side on each pool every 10 s.
- App-level `setup:` — publishes the mock USDC + WETH packages and mints the initial supply
  distribution to alice/bob/carol.
- `walletServer()` + `frontend()` — the in-process signer adapter + Vite dev server.

Source:
[`examples/wallet/`](https://github.com/mysten-incubation/devstack/tree/main/examples/wallet)

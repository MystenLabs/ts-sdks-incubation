---
title: Testing
description: The three-suite testing layout for devstack apps — unit, e2e, and browser.
---

Devstack apps test at three levels: **unit** tests over generated bindings, **e2e** tests against a
booted stack, and **browser** tests that drive the app with the dev wallet. Each level uses a
different devstack build integration.

| Suite   | Runs against        | Build integration                                  |
| ------- | ------------------- | -------------------------------------------------- |
| Unit    | generated bindings  | `@mysten-incubation/devstack/vitest`               |
| E2e     | a booted stack      | `@mysten-incubation/devstack/vitest` + `apply`     |
| Browser | the running app + dev wallet | `@mysten-incubation/devstack/playwright`   |

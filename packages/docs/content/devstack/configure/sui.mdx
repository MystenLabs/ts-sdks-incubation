---
title: Sui config
description: Declaring the local Sui network, RPC, faucet, and indexer for a stack.
---

The `sui()` member declares the local Sui network that backs a stack — the node, RPC endpoint,
faucet, and GraphQL indexer. Everything else in the stack (packages, accounts, services) is wired on
top of this network.

---
title: Packages
description: Declaring local Move packages, the per-stack registry, and how packages are published and discovered.
---

Local Move packages are declared with `localPackage(...)` and published into the stack on boot. Each
package gets an id in the per-stack registry, and that id is injected into the generated config at
runtime.

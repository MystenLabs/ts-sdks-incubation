---
title: Vitest
description: Unit and chain-aware test config.
---

```ts
// vitest.config.ts
import { defineDevstackVitestConfig } from '@mysten-incubation/devstack/vitest';

export default defineDevstackVitestConfig(); // unit tests
export default defineDevstackVitestConfig({ chain: true }); // chain-aware (AccountPool globalSetup)
```

`{ chain: true }` adds a global setup that pre-funds accounts and exposes them to tests via the
runtime helper, so chain-aware unit tests don't faucet-per-test.

---
title: Forking
description: Running a local fork of a public network — replay against real upstream state while keeping writes local.
---

Fork mode (`sui({ mode: 'fork' })`) runs a local `sui-fork` container against an upstream public
network, so you can replay against real on-chain state while keeping all writes local. See
[Live networks & forking](/devstack/live-networks) for the current fork documentation.

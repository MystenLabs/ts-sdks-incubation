---
title: Local Development
description: How the local supervisor, manifest, and generated files fit together.
---

Local mode is the default. `sui()` starts an in-stack local network, and any member that consumes
Sui can also trigger the default `sui()` auto-mount when no explicit Sui member is present.

```ts
import { defineDevstack, account, localPackage, wallet } from '@mysten-incubation/devstack';

const alice = account('alice');
const hello = localPackage('hello', {
	sourcePath: './move/hello',
	publisher: alice,
});

export default defineDevstack(alice, hello, wallet({ accounts: [alice] }));
```

State is scoped by app and stack name:

```txt
.devstack/
  stacks/
    main/
      manifest.json
      projection.v1.json
      events.ndjson
      commands.ndjson
      snapshots/
      runtime/
```

Generated files are separate. By default they go to `src/generated`; override with the trailing
options bag:

```ts
export default defineDevstack(alice, hello, {
	stackName: 'local',
	codegen: {
		outputDir: 'src/generated',
		stackSubdir: null,
	},
});
```

Useful commands:

```bash
devstack up --renderer tui
devstack up --renderer plain
devstack apply
devstack status --json
devstack logs wallet
devstack down
```

Use a different stack name when you want independent keys, snapshots, and runtime state:

```bash
DEVSTACK_STACK=ci devstack apply --renderer plain
```

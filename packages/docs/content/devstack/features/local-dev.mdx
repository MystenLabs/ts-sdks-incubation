---
title: Local Development
description: How the local supervisor, manifest, and generated files fit together.
---

Local mode is the default. `sui()` starts an in-stack local network; include it once in any stack
whose members depend on Sui.

```ts
import { defineDevstack, account, localPackage, sui, wallet } from '@mysten-incubation/devstack';

const localnet = sui();
const alice = account('alice');
const hello = localPackage('hello', {
	sourcePath: './move/hello',
	publisher: alice,
});
const devWallet = wallet({ accounts: [alice] });

export default defineDevstack({ members: [localnet, hello, devWallet] });
```

State is scoped by app and stack name:

```txt
.devstack/
  stacks/
    main/
      manifest.json
      projection.v1.json
      snapshots/
      runtime/
```

Generated files are separate. By default they go to `src/generated`; override with the trailing
options bag:

```ts
export default defineDevstack({
	members: [localnet, hello],
	stackName: 'local',
	codegen: {
		outputDir: 'src/generated',
		stackSubdir: null,
	},
});
```

Useful commands:

```bash
devstack up --renderer tui
devstack up --renderer plain
devstack apply
devstack status --json
```

Use a different stack name when you want independent keys, snapshots, and runtime state:

```bash
DEVSTACK_STACK=ci devstack apply
devstack apply --stack ci
```

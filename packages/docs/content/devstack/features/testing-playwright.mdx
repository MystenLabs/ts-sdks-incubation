Use the `playwright` subpath from the Playwright config and from e2e specs.

```ts title="playwright.config.ts"
import { defineDevstackPlaywrightConfig } from '@mysten-incubation/devstack/playwright';

export default defineDevstackPlaywrightConfig({
	command: 'pnpm dev',
});
```

The preset sets a single worker, disables full parallelism, starts the web server command, and
discovers the app endpoint from the devstack manifest with a cold-start fallback.

For suites that require a verified manifest before specs run, add a thin global setup module:

```ts title="e2e/global-setup.ts"
import { buildGlobalSetup } from '@mysten-incubation/devstack/playwright';

export default buildGlobalSetup({
	requireEndpoints: ['app', 'wallet'],
});
```

Then point the config at that file:

```ts title="playwright.config.ts"
import { defineDevstackPlaywrightConfig } from '@mysten-incubation/devstack/playwright';

export default defineDevstackPlaywrightConfig({
	globalSetup: './e2e/global-setup.ts',
});
```

Current test helpers include `connectAs`, `selectAccount`, `createWalletAdapter`,
`loadStackManifest`, and `readStackContext`.

```ts title="e2e/connect.spec.ts"
import { expect, test } from '@playwright/test';
import { connectAs, createWalletAdapter } from '@mysten-incubation/devstack/playwright';

test('connects alice', async ({ page }) => {
	await page.goto('/');
	await connectAs(page, 'alice');

	const wallet = createWalletAdapter();
	const accounts = await wallet.listAccounts();
	expect(accounts.some((entry) => entry.name === 'alice')).toBe(true);
});
```

The account switch helper uses `globalThis.__devstackDAppKit__`. Populate that slot in your app's
dapp-kit setup when you want Playwright to switch accounts without clicking through wallet UI state.

---
title: Plugins
description: Current plugin-author entry points.
---

A plugin is a function that returns a stack member. The root package exports the authoring helpers;
the `contracts` and `substrate` subpaths expose the same lower-level vocabulary for isolated
imports.

```ts
import { Effect } from 'effect';
import {
	capabilities,
	defineNodePlugin,
	defineTag,
	type CodegenableDecl,
} from '@mysten-incubation/devstack';

interface KeyValueResolved {
	readonly url: string;
}

const keyValueTag = defineTag<'kv', KeyValueResolved>('kv', 'kv');

export const keyValue = () =>
	defineNodePlugin({
		provides: keyValueTag,
		consumes: [] as const,
		kind: 'leaf-long-running',
		rebootCost: 'cheap',
		acquire: () => Effect.succeed({ url: 'http://127.0.0.1:6379' }),
		capabilities: (resolved) => {
			const codegen: CodegenableDecl<KeyValueResolved, 'kv'> = {
				kind: 'codegenable',
				emitterName: 'kv',
				outputPath: 'kv.ts',
				emit: () => Effect.succeed({ kv: resolved }),
			};
			return capabilities(codegen);
		},
	});
```

Compose the plugin like any built-in factory:

```ts
import { defineDevstack } from '@mysten-incubation/devstack';
import { keyValue } from './devstack/key-value.js';

export default defineDevstack(keyValue());
```

Use direct member references for cross-plugin dependencies. For example, if a plugin needs an
account, accept the `account('name')` member and project its provided tag into the plugin's
`consumes` tuple.

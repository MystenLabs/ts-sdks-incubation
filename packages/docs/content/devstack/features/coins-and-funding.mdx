---
title: Coins and Funding
description: Current coin declaration and funding forms.
---

The `coin` namespace has explicit forms. There is no string-guessing `coin(value)` entry.

```ts
import { defineDevstack, account, coin, localPackage, sui } from '@mysten-incubation/devstack';

const localnet = sui();
const publisher = account('publisher');

const managed = localPackage('managed_coin', {
	sourcePath: './move/managed_coin',
	publisher,
});

const managedCoin = coin.fromPackage(managed, 'MANAGED_COIN');

const alice = account('alice', {
	funding: [
		{ coin: 'sui', amount: 1_000_000_000n },
		{ coin: managedCoin, amount: 1_000n },
	],
});

export default defineDevstack({ members: [localnet, alice] });
```

Available forms:

- `coin.builtin('sui')` uses the protocol SUI type.
- `coin.fromPackage(member, witness)` adds a dependency edge on the publishing member. Local package
  coins that keep the TreasuryCap with the publisher also contribute a centralized funding strategy,
  so account funding can mint them without a bespoke seed action.
- `coin.known(fullCoinType)` resolves an on-chain type through metadata reads.

Funding is best-effort for custom strategies. Missing strategies are treated as a no-op for
cross-coin funding entries, while explicit or default SUI funding fails loudly if no faucet-bearing
strategy exists for the active chain.

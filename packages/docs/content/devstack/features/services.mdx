The root package exports current service factories in lowercase. Compose only the behavior the
options actually support.

## Walrus

Local mode starts a local cluster. Use `seedAccounts` when you want the WAL swap/admin path wired.

```ts
import { defineDevstack, account, sui, walrus } from '@mysten-incubation/devstack';

const admin = account('admin');

export default defineDevstack(
	sui(),
	admin,
	walrus({
		local: {
			nodeCount: 1,
			shards: 4,
			seedAccounts: [admin],
		},
	}),
);
```

Known mode requires explicit on-chain ids and an explicit node list. Network shortcuts only provide
URL defaults where the package has them.

## Seal

Local keygen mode requires a signer account:

```ts
import { defineDevstack, account, seal } from '@mysten-incubation/devstack';

const publisher = account('publisher');

export default defineDevstack(
	publisher,
	seal({
		mode: 'local-keygen',
		signer: publisher,
	}),
);
```

Live and fork-known modes reference existing key servers and do not expose a local manager.

## DeepBook

Local mode is a wrapper around explicit local deployment ids and requires a publisher. Known mode
requires `packageId` and `registryId`.

```ts
import { defineDevstack, account, deepbook } from '@mysten-incubation/devstack';

const publisher = account('publisher');

export default defineDevstack(
	publisher,
	deepbook({
		mode: 'known',
		packageId: '0x...',
		registryId: '0x...',
	}),
);
```

The current DeepBook surface does not claim local pool creation, Pyth, margin, or market-maker
behavior unless those fields are present in the resolved value.

## Known on-chain dependencies

Use `knownPackage(name, { packageId })` for fixed deployed modules:

```ts
import { defineDevstack, knownPackage } from '@mysten-incubation/devstack';

const registry = knownPackage('registry', {
	packageId: '0x...',
	mvrPlaceholder: '@demo/registry',
});

export default defineDevstack(registry);
```

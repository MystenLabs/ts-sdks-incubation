---
title: Devstack integration
description: Surface devstack-resolved accounts in dev-wallet without leaking keys to the frontend.
---

`@mysten-incubation/dev-wallet` ships a `DevstackSignerAdapter` that pairs with the `walletServer()`
plugin from `@mysten-incubation/devstack`. Together they expose every account materialized by
`devstack up` — `cliSigner`, `envSigner`, `generatedKeypair`, anything that lands in `ctx.accounts`
— to your dApp without shipping private keys into the bundle.

The adapter mirrors `RemoteCliAdapter`'s out-of-process model: keys live in the supervisor process,
transactions are signed via HTTP, and the manifest carries the discovery URL so the frontend wires
up automatically.

## Setup

### 1. Add the wallet-server plugin

```ts
// devstack.config.ts
import {
	codegen,
	defineDevstackConfig,
	sui,
	vite,
	walletServer,
} from '@mysten-incubation/devstack';

export default defineDevstackConfig({
	app: 'my-app',
	accounts: {
		publisher: {},
		alice: {},
	},
	plugins: [
		sui({ version: 'devnet-v1.71.0' }),
		// ...your app plugins
		codegen(),
		walletServer({ port: 9420 }),
		vite({ port: 5173 }),
	],
});
```

`walletServer()` registers a Service action that runs an in-process HTTP server bound to the
supervisor lifecycle. It writes the paired URL — including a fresh per-stack token — into
`manifest.registry.services` as the `wallet-server` entry, so the frontend has everything it needs
to discover and authenticate.

### 2. Wire the adapter into dev-wallet

```ts
// src/dapp-kit.ts
import { devWalletInitializer } from '@mysten-incubation/dev-wallet';
import { createDevstackAdapterFromManifest } from '@mysten-incubation/dev-wallet/adapters';
import { createDevstackDappKit } from '@mysten-incubation/devstack/react';
import { configureDevstackPanels, devstackPanels } from '@mysten-incubation/devstack-wallet-panels';
import { manifest } from 'virtual:devstack-manifest';

import { deployment } from './generated/deployment.js';

configureDevstackPanels(manifest);

const devstackAdapter = createDevstackAdapterFromManifest(manifest);

export const { dAppKit } = createDevstackDappKit({
	defaultNetwork: 'localnet',
	localnetRpcUrl: deployment.rpcUrl,
	walletInitializers: [
		devWalletInitializer({
			adapters: devstackAdapter ? [devstackAdapter] : [],
			panels: devstackPanels(),
			autoConnect: true,
			autoApprove: true,
			mountUI: true,
		}),
	],
});
```

`createDevstackAdapterFromManifest` reads `manifest.registry.services[name='wallet-server']` and
returns either a configured adapter (when devstack is running) or `null` (before the first
`pnpm localnet:up`). Hand the adapter to `devWalletInitializer` and you're done — every named
account devstack resolved is now a wallet-standard account in dApp Kit.

## What you get

- **Server-side signing.** Transactions go to the wallet-server's
  `POST /api/v1/devstack/sign-transaction` endpoint. Keys never leave the supervisor.
- **Auto-pairing.** A 256-bit token is generated on each `devstack up` and embedded in the
  manifest's `endpointLabel`. Stale tokens fail the next `initialize()` cleanly.
- **Multi-coin faucet panel.** `configureDevstackPanels(manifest)` + `devstackPanels()` adds Faucet
  / Packages / Network tabs to the floating dev-wallet drawer. The Faucet panel calls the localnet
  faucet for SUI top-ups and signs `mint(treasuryCap, amount, recipient)` as the publisher for any
  token registered in the manifest.
- **Custom panels.** Drop additional `WalletPanelDescriptor` entries into the `panels` array to
  mount your own Lit elements as wallet tabs — they receive `.wallet`, `.activeAddress`, and
  `.client` properties automatically.

## Caveats

- The wallet-server is localnet-only. `walletServer()` calls `requireLocalnetCtx`, so live-net
  (`devstack deploy --network testnet`) skips the service entirely.
- `signPersonalMessage` is unsupported, matching `RemoteCliAdapter`. The server signs BCS-serialized
  `TransactionData` only.
- The token is regenerated on every supervisor restart. Don't persist it client-side; the manifest
  is the source of truth.
